# PGN 与仙灵扩展 v1

## 用途与入口

普通棋局使用标准 PGN/SAN；仙灵棋局使用其项目内扩展。唯一实现为 `engine/pgn.ts`，浏览器、生成版 HTML 与实验 CLI 复用它，合法性全部由现有规则引擎判断。

页面棋盘下方的“棋谱导入 / 导出（PGN）”支持粘贴或文件导入。导入完毕停在末局面、关闭电脑走棋；翻阅按钮切换局面和重复历史，现有永琳评估 Worker 自动分析当前局面。浏览不会删除后续着法，导出仍是完整主线；在历史局面落子或悔棋则修改主线。无法解析的棋谱不会覆盖当前对局。

## 标准部分

遵循 [PGN Specification and Implementation Guide](https://www.saremba.de/chessgml/standards/pgn/pgn-complete.htm) 的 SAN、七项基本标签、结果标记与 FEN/SetUp。

```pgn
[Event "Example"]
[Site "?"]
[Date "????.??.??"]
[Round "?"]
[White "?"]
[Black "?"]
[Result "0-1"]

1. f3 e5 2. g4 Qh4# 0-1
```

- 普通着法 `e4`、`Nf3`；吃子 `exd5`、`Bxc6`；易位 `O-O` / `O-O-O`；升变 `e8=Q`；将军 `+`、将杀 `#`。
- 同类棋子消歧基于合法走法，考虑钉住。例如 `Nbd2`、`R1e2`，必要时写完整出发格。
- 标准初始阵容省略 FEN；仅含标准棋子的自定义局面使用 `[SetUp "1"]` 和六字段 `[FEN "..."]`。第三方工具需要支持 FEN 初始局面；不能保证每个平台接受每种自定义布局。
- 保留认输、超时、协议和棋等输入结果，即使棋盘本身尚未自然终局。分析仍遵循本游戏已有规则；未新增 FIDE 和棋申诉或死局裁定系统。
- 标准 FEN 不含弹药；导入置零。仅有标准棋子时弹药不影响走法。
- 目前每次导入一个游戏、只取主线。可读取花括号/分号注释、NAG 和嵌套变例，但会跳过并提示，重新导出不保留它们。多游戏文件、其他变体、非法或歧义走法会报错。

## 仙灵扩展（本项目协议，不是第三方通行标准）

初始状态包含仙灵棋子或消失标记时附加：

- `[Variant "Touhou Fairy Chess"]`
- `[TFCVersion "1"]`
- `[TFCState "..."]`：`encodeURIComponent(JSON.stringify(state))`。状态只含 `b, turn, cas, ep, half, full, ammo`；棋子含 `t,c` 及可选 `mark`。类型键使用引擎内部稳定 ID，不用角色显示名称。

这保留初始部署、双方弹药、易位权、过路兵目标、计数和消失标记。导入从这些字段重建局面，再通过同一引擎逐步走棋。版本未知即拒绝；未来若规则变化使旧谱无法还原，需要明确迁移或新协议版本，不能偷偷重解释。

普通棋子的着法继续用 SAN。特殊棋子的着法是：

```text
Xkoishi_b8xc7
Xfairy_b2-c3
Drabbit_c1_d2
```

`X<棋子ID>_<出发格>-<终点格>` 表示移动，`x` 表示吃子；升变后缀 `=<棋子ID>`。`D<打入棋子ID>_<施法者格>_<落点格>` 表示打入，写出施法者可区分多个来源。两者均可附加 `+` / `#`。连续跳跃记录合法最终落点，不记录不消耗回合且不产生中途效果的路径。第三方平台不会自动认识这些扩展。

PGN 用于交换和复盘，JSON 仍是实验检查点，额外保存搜索深度、耗时、评分和源码身份；不能用 PGN 代替续跑数据。

## 妖精实验输出

`lab/piece_value.py` 的每局结束（含未决）后，在 `games/` 同时生成同名 `.json` 与 `.pgn`。未决 PGN 的结果是 `*`。普通兵对照输出标准 PGN；妖精组输出扩展 PGN。实验 ID 和结束原因附加为标签。

已有检查点无需重跑，可单独转换：

```powershell
conda activate TouhouChess
python lab/piece_value.py --out lab/out/fairy-pilot --export-pgn
```

转换会读取保存的初始阵容和走法，使用当前规则逐步验证，输出每局 PGN；不会继续实验或改写 JSON。如旧版走法与当前规则不兼容会报错，不伪造转换结果。运行正式实验期间请保留原代码；本次新增文件和引擎接口会改变严格续跑指纹，转换命令无需改变或绕过原实验校验。

## 验证

`npm run test:pgn` 覆盖标准 SAN/FEN、易位、过路兵、升变、合法着法消歧、黑先、结果、注释/变例、非法输入、仙灵往返和界面控制器的导入/浏览/分支/悔棋。已通过完整构建、原金标准及实验检查点测试，并在本地浏览器验证标准棋谱导入、回退分析和导出。未宣称已经逐个平台验证第三方导入。
