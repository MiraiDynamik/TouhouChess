# 東方西洋棋

**Touhou Fairy Chess**。

把东方 Project 角色与国际象棋结合的棋盘游戏。每方有 **45 点预算**，可以使用标准国际象棋阵容，也可以选择具有特殊能力的棋子，自由搭配阵容后对弈。

支持双人同机对弈、四档电脑对手和电脑自对弈，并提供悔棋、棋盘翻转、中英文切换及局面分析。

## 开始游戏

### 直接试玩

打开项目中的 [touhou-chess.html](touhou-chess.html)，即可使用已构建的单文件版本。

### 本地运行

安装 Node.js 22.12 或更新的受支持版本，在项目目录打开终端：

```sh
npm ci
npm run dev
```

打开终端显示的地址，通常是 `http://127.0.0.1:5173/`。端口被占用时，以终端实际显示的地址为准。运行游戏不需要 Python 或后端服务。

## 怎么玩

1. 在部署阶段选择白方或黑方，点选棋子，再点击允许的棋盘位置放置。点击已放置的棋子可以移除。
2. 每方花费不能超过 45 点，且必须恰好有一个将军对象。剩余点数作为弹药，可供具有打入能力的棋子使用。
3. 想从熟悉的国际象棋开始，可以分别给双方点击“香草阵型”。
4. 点击“开始对局”，先点己方棋子，再点目标格。遇到升变或多种动作时，选择要执行的动作。
5. 在棋盘下方选择电脑执方和难度；电脑关闭时可双人同机对弈。

棋子的特殊能力见 [规则说明](rules/rulebook.md)。规则书包含尚在设计中的内容，当前可用棋子以游戏内列表为准。

## 电脑难度

| 对手 | 特点 |
|---|---|
| 琪露诺（Easy） | 经常失误，适合熟悉规则 |
| 河城荷取（Normal） | 比琪露诺稳定，仍会犯错 |
| 犬走椛（Hard） | 搜索更深，失误较少 |
| 八意永琳（Lunatic） | 不刻意放水，通常使用约 3 秒思考一手 |

可开启“引擎评估”进行局面分析。分差为正表示白方占优，为负表示黑方占优；评估仅供参考，不代表必胜或必败。

## 常见问题

**棋盘正常变化，但文字不更新？**

请对游戏页面停用会改写网页文字的阅读或排版扩展，再刷新。已确认 Bionic Reading 会造成此问题。
